# stayin' alive — Demo

Static, traceable demonstration of the LegaSynth / *stayin' alive* pipeline:

1. original heart-sound recording and story;
2. processed heartbeat material and time–energy plots;
3. selected planning artifacts;
4. Stage 1 theme MIDI and Stage 2 completed MIDI;
5. Stage 3 final audio mix.

The repository contains only the static demonstration and curated case assets. It
does not include the local generation backend, model weights, API credentials, or
runtime job directories.

## Local preview

```powershell
npm install
npm run dev
```

## Deployment

Pushes to `main` are built and deployed automatically with GitHub Actions and
GitHub Pages.
